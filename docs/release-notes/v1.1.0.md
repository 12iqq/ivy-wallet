**This version installs as a new app next to the one you have.** Move your data over once with the steps below. After
that, updates install over it as usual.

### What changed
- **No more data going to anyone.** Crash reports used to go to the original Ivy Wallet team's Firebase project. That's
  removed, along with an unused poll screen that would have sent a vote and a device ID to their database. The only
  thing the app downloads now is exchange rates. [PRIVACY.md](https://github.com/12iqq/ivy-wallet/blob/main/PRIVACY.md)
  lists what each permission is for.
- **Signed with a private key.** Earlier versions were signed with a key anyone could find in this repo, so someone
  could have made a fake "update" that installs over the app. Android doesn't let an app change its key, which is why
  1.1.0 is a separate app.
- The location and lock-screen permissions are gone. Nothing used them.
- The new app has the green Ivy icon, so you can tell it apart from the old gray one while you move over.
- A rewritten README and a [step-by-step guide](https://github.com/12iqq/ivy-wallet/blob/main/docs/How-to-use.md).

### Moving your data
1. In your current app, go to **Settings → Backup data** and save the file.
2. Install `IvyWalletUAE-v1.1.0.apk` below and open it (the green icon).
3. Tap **Offline account**, then **Import backup file**, and pick the file from step 1.
4. Set up again what the backup doesn't include:
   - **Settings → Auto-add transactions**: the mode, your banks and your card links. On Android 13 or newer, first
     allow restricted settings for the new app (**Settings → Apps → Ivy Wallet UAE → ⋮**).
   - **Google Wallet payments**, if you used it: allow notification access for the new app.
   - **Settings → Automatic backup**: pick the backup file again.
   - **Settings → Notifications** and **Transaction look**, if you had changed them.
   - Home-screen widgets, if you had any.
5. Once everything looks right, uninstall the old app (the gray icon). Until you do, both apps read your SMS, so each
   transaction shows up twice.

### New: the Windows app
`IvyWalletUAE-Desktop-v1.1.0.msi` below is a Windows app for looking at your money on a bigger screen: your accounts
and cards, monthly and yearly reports, all your transactions with search, and recurring charges. It reads the backup
the phone app saves, so you keep adding transactions on the phone. You can't add or change anything on the computer
yet.

1. In the phone app, set **Settings → Automatic backup** to **Daily** and save the file in your Google Drive.
2. Install [Google Drive for desktop](https://www.google.com/drive/download/) so the file is on your computer too.
3. Install `IvyWalletUAE-Desktop-v1.1.0.msi`. Windows may say it protected your PC, because not many people have
   downloaded the app yet. Click **More info → Run anyway**.
4. Open **Ivy Wallet UAE** from the Start menu and choose the backup file.
