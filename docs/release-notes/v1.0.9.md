**Install:** download `IvyWalletUAE-v1.0.9.apk` below and open it. It updates the app you already have and keeps your data.

### Add a note from the notification
- A purchase or income auto-add finds now gets its own notification with **Add note**. Type the part the bank's
  text can't tell (the film you saw, what you ordered) without opening the app. When a scheduled check finds
  several at once you still get one summary notification instead.
- The note becomes the transaction's description. If the transaction was already added, the note goes straight into
  its description, after anything already there.
- Transactions added without review now get an **Added: …** notification with the same Add note reply. Turn it off
  with the other detected-transaction notifications in Settings → Notifications.
- The review list has a note field too, and a transaction's notification goes away once you add or skip it in the app.

### Find duplicates
- New in Settings: **Find duplicates**. It lists transactions of the same kind, account and amount on the same day,
  side by side and newest first, with their name, category, time, description and bank details.
- **Delete** removes the extra copy (tap twice to confirm). **Not duplicates** hides a group for good when they
  really are two separate transactions.
- Handy after importing a backup into an app that already had some of the same data.
