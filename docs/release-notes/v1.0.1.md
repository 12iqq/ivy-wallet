**Install:** download `IvyWalletUAE-v1.0.1.apk` below and open it. It updates the app you already have and keeps your data.

### Fixed
- **Categories missing after restoring a backup.** Categories, with their colours and icons, now show up as soon as the
  import finishes. If you already imported with v1.0.0, they're there too: they show once you update, or if you
  fully close and reopen the app.
- The Auto-add row in Settings is aligned like the other rows.

### Changed
- **Linking cards is clearer.** In Settings → Auto-add → a bank, you add a link in two steps: which messages
  (one card by its last 4 digits, or *Everything else*) and which account. Then tap **Add ··1234 → Liv**. Tapping
  an account doesn't save anything by itself any more, so you can't create an "any card" link by accident.
- **Card endings live in one place.** The last 4 digits are now set only in Auto-add → bank, not on the account.
  Any you had typed on an account are moved over automatically.
